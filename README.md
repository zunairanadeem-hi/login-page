# Modern Login Page UI

A clean, responsive, and modern login form interface built using HTML5 and CSS3, enhanced with Boxicons and custom background particle animations.

## ✨ Features

- **Responsive Design:** Adapts cleanly to different screen sizes using the viewport meta tag.
- **Icon Integration:** Uses [Boxicons](https://boxicons.com/) for crisp username and password input icons.
- **Interactive Elements:** Includes "Remember Me" checkbox, "Forgot Password?" link, and a registration redirect prompt.
- **Form Validation:** Built-in HTML5 `required` attributes on input fields to prevent empty submissions.
- **Animated Background:** Styled with custom CSS (`style2.css`) and particle effects (`particesanimate.css`).

## 🛠️ Technologies Used

- **HTML5** – Page structure and form elements
- **CSS3** – Layout styling and particle animations
- **Boxicons (v2.1.4)** – UI icons via CDN
